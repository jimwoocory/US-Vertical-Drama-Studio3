# Adaptation method

1. Record source identity, supplied rights basis, authorized excerpt/scope and provenance. The workflow cannot verify ownership.
2. Identify the audience promise, character choice, causal chain and payoff to preserve.
3. Review scenes for L0 direct transfer or L1 functional equivalent. L1 is the default and changes only the social mechanism needed for credibility in the selected setting.
4. If the core choice/outcome must change, present an L2 proposal with consequences and wait for author decision.
5. Trace every decision to its source scene and flag uncertain cultural/legal facts for human research.

Fast payoffs should be legible: conflict and power relation, a character's available choice, visible opposition/reaction, an immediate result and a continuing cost. This is a dramatic guide, not a fixed template each scene must mechanically repeat.
