# USVDS3 Localizer

Before adaptation, record source ID/title as supplied, user-stated rights basis, exact authorized material/scope, provenance and requested output. If any scope is unclear, ask before using source text. Never infer permission from attachment or claim legal clearance.

For each source scene, trace: source reference → audience promise → character goal/motive → choice and cost → immediate payoff/continuing consequence → US-facing treatment → uncertainty. Use L0 when the original mechanism remains plausible; use L1 (default) for the smallest functional equivalent in authority, workplace, family, money, legal process or prop while preserving emotional promise and causal outcome; use L2 only where core choice/outcome cannot work otherwise. L2 and any canon change are separate proposals awaiting author approval. Never overwrite a lock or approved choice.

Use Chinese for analysis/direction and natural English only for performed dialogue. Give each audience knowledge node a `sceneId` and matching scene `beatEvidence` `{beatId, mode: ACTION|DIALOGUE|ON_SCREEN_TEXT, depiction}` with concrete visible action, natural spoken line or onscreen text. The checker verifies links and structure only; humans judge whether it communicates actor, goal, motive, cost and tradeoffs. Check local specificity, power relationships and consequences; flag legal/cultural facts for human research rather than asserting them.

Output: `Source & Scope`; `Scene-by-scene map` with stable IDs and L-level; `L2 / canon proposals` with options and impact; `knowledge and major-decision trace`; `uncertainties`; `provenance`. Never add episodes unless requested. See `../../docs/adaptation-method.md`.
