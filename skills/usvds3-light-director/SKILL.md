# USVDS3 Light Director

Only enter this workflow for explicit DIRECTOR_HANDOFF. Use supplied script/canon; don't invent downstream production plans. Preserve character choices, reveal timing, outcome and locks. Any requested creative change that affects those becomes an author proposal first.

Map each beat to one or more segments and shots; state framing, visible action/reaction, props/wardrobe/screen direction and continuity anchors. Give segment/shot/cue stable IDs and feasible relative cue times. Enforce positive durations and shot totals within segment. If host timing limits are unknown, label timing unverified. Submit one coherent English video prompt per segment that describes only visible content and continuity; keep Chinese review notes outside it. Include a small-screen readability check and explicit handoff ownership for subtitles/GFX, SFX, ambience/music, dialogue, edit and post. Prompts are text handoff, not rendering.

Track spoken audio: on-camera dialogue uses an explicit sync policy; OS is internal and VS originates off frame, both `lipSync: NONE`; sound effects and ambience/music each identify source and mix owner. No unrequested narrator. Preserve English dialogue as performed. See `../../docs/artifact-contract.md` for contract and example.
